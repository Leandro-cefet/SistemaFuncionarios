# Cadastro de Funconários em Java
## Descrição
O sistema permite cadastrar funcionários, alterar dados, aplicar reajustes salariais, demitir funcionários e calcular a folha salarial dos funcionários ativos.
## Como executar
1. Compile o programa
2. Execute a classe principal
## Descrição das classes 
- Classe Departamento:
  Responsável por armazenar os funcionários de um departamento, cadastrar novos funcionários, listar os dados cadastrados
  e calcular a folha salarial dos funcionários ativos.
- Classe Funcionario:
  Responsável por armazenar e gerenciar os dados de um funcionário, como nome, CPF, cargo, salário e status de atividade. Também realiza operações
  como reajuste salarial, alteração de dados e demissão.
- Classe TesteSistema:
  Classe principal do sistema. Responsável por executar os testes e demonstrar o funcionamento das funcionalidades do projeto.
## Tecnologia utilizada
- Java, JDK 21, Eclipse IDE
